Bulk cost calculation and Zoho sync system with overlap prevention

- SCHEMA: Added pendingCostSync, costsCalculatedAt, lastCostSyncAt to Invoice/Quote/SalesOrder
  Added @@index([pendingCostSync]) on all 3 models for efficient pending-doc queries

- NEW netlify/functions/bulk-calculate-costs.ts
  Iterates all docs in DB, fetches full Zoho detail, runs calculateDocumentCosts()
  Stores calculated values + pre-built Zoho PUT payload in items JSON
  Sets pendingCostSync=true only when field values actually changed
  3-layer overlap prevention:
    1. Global run lock via SystemSetting cost_calc_running (30min timeout)
    2. Per-doc skip when costsCalculatedAt >= zohoModifiedTime
    3. Field-level diff: only queues changed fields
  Params: docTypes, force, dryRun, limit, batchDelay
  Processes in batches of 10 with configurable delay

- NEW netlify/functions/sync-costs-to-zoho.ts
  Reads all docs where pendingCostSync=true
  Pushes pre-built pendingZohoFields payload to Zoho Books via PUT
  In-memory loop guard prevents double-push within 60s
  Sets pendingCostSync=false + lastCostSyncAt=now on success
  Leaves pendingCostSync=true on failure for automatic retry
  Params: docTypes, dryRun, batchDelay

- NEW src/app/api/bulk-calculate-costs/route.ts
  GET: returns lock status + pending doc counts per type
  POST: proxies to bulk-calculate-costs Netlify function

- NEW src/app/api/sync-costs-to-zoho/route.ts
  GET: returns pending counts + last sync timestamps per type
  POST: proxies to sync-costs-to-zoho Netlify function

- MODIFY src/lib/trainingData.ts
  Added Bulk Cost Calculation training module covering
  two-phase process, overlap prevention, all params, API endpoints
